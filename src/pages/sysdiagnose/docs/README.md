# Sysdiagnose Powerlog documentation

[SCHEMA.md](./SCHEMA.md) is the single, source-grounded reference for the
Powerlog tables used by Sysdiagnose analysis. It starts with the data model,
timestamp calibration, and unit-confidence rules before documenting each
table and column.

[PAGES.md](./PAGES.md) is the source inventory and implementation research for
the WiFi, Storage, Thermal, Device, and Crashes tabs.
